# KijaniKiosk Cloud Service Model

## IaaS — Infrastructure as a Service

IaaS provides virtualized infrastructure such as servers, storage, and networking while leaving the customer responsible for managing the operating system, applications, and much of the infrastructure configuration.

## PaaS — Platform as a Service

PaaS provides a managed application platform where the team can deploy and run applications without having to manage the underlying servers and operating systems.

## SaaS — Software as a Service

SaaS provides a complete software application that users consume as a service, with the provider managing the application and underlying infrastructure.

## Recommendation: PaaS

KijaniKiosk should start with **PaaS** because an early-stage platform benefits from shipping features quickly without requiring a large team to manage servers, operating systems, and infrastructure maintenance. PaaS reduces operational overhead while still giving the development team control over the application, deployment process, and data, unlike SaaS where the team would primarily consume an existing application. It can also be more cost-effective at an early stage because the team does not need to dedicate significant resources to infrastructure management before the platform has grown.

IaaS would provide greater infrastructure control, but that additional control also introduces more configuration, maintenance, and operational responsibility. As KijaniKiosk grows and develops more demanding infrastructure or customization requirements, the team could reconsider IaaS or adopt a hybrid approach. For the initial stage, PaaS provides a practical balance between **control, development speed, operational effort, and cost**.
